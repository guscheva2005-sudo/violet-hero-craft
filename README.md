# Violet Hue Hero

Используй стиль загруженного референса.

Создай Hero-секцию для лендинга-портфолио вайбкодера.

 Хочу взять из референса: шрифт основного шрифта должен быть от 18 до 22 пикселей, расположение текста, размер деления между темами, стиль визуального элемента . Хочу поменять розовые оттенки на фиолетовые оттенки (от белого до сине-фиолетового)

Остальное не трогай.
